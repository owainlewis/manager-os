# Decision log entry

## When to use
When I make a decision that I or the agent will need to remember.

## Reads
- What I tell you
- The thread or meeting where it was decided

## Steps
1. Write one line: the date, the decision and why, in my words.
2. Add a link to where it was decided.
3. Add a date to check whether it worked, if I give one.
4. Show me the line, then add it to the top of Decisions.

## Output
One new line in Decisions.

## Rules
- One line per decision.
- Record the decision, not the discussion.
