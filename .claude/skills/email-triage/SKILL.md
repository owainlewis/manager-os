# Email triage

## When to use
Once a day, by hand or as a morning routine.

## Reads
- My email from the last 24 hours
- My Me page in Notion (to judge what matters to me)
- Open Linear tasks (to avoid duplicates)

## Steps
1. Read every email received in the last 24 hours.
2. Sort each one: needs my action, needs a reply only, FYI, or noise (newsletters, notifications, sales).
3. For each email that needs my action, check Linear for an open task about it. If none exists, create one: a title that starts with a verb, the email linked, and a one-line next step.
4. For each email that needs a reply only, draft the reply. Don't send it.
5. Comment a summary on today's triage task.

## Output
A comment with: tasks created (linked), drafts written, and anything I wasn't sure how to sort.

## Rules
- Never send, archive or delete email.
- One task per action, not per email.
- Don't invent deadlines. Use the date in the email or none.
