# Meeting follow-up

## When to use
After any meeting with actions.

## Reads
- The meeting transcript in Zoom
- Linear

## Steps
1. List every action agreed, with who agreed to it and by when, quoted with a timestamp.
2. Mark any action with no owner or no date as "not agreed".
3. Show me the list and wait.
4. For each action I approve, create a Linear task with the owner, the due date and a link to the transcript.
5. For each "not agreed" action, draft a one-line message asking who owns it.

## Output
Linear tasks with owners, plus draft messages for the open actions.

## Rules
- Never send the messages.
- Don't copy the transcript or a summary into Notion. It stays in Zoom.
