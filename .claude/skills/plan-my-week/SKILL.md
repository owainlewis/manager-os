# Plan my week

## When to use
A routine every Monday at 8am.

## Reads
- This week's calendar
- Last week's email and Slack
- Linear: tasks due this week and carried over
- Notion: Goals, and last week's entries in Decisions

## Steps
1. List this week's fixed commitments. Flag any day with under two hours free.
2. List the tasks due this week and anything carried over from last week.
3. List requests from last week that still have no reply or task.
4. Mark which goal each item serves, or "no goal".
5. Propose three priorities, each tied to a goal.
6. Suggest what to drop or delegate.

## Output
A comment on this week's planning task.

## Rules
- Propose, don't decide.
- Never create or move calendar events.
- If the week has more work than time, say so plainly.
