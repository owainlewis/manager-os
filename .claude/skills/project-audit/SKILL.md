# Project audit

## When to use
When I'm worried about a project, or before a status meeting about it.

## Reads
- The project's Linear issues and their history
- Its Slack channel
- Its code repo, if you can reach it

## Steps
1. List what changed in the last 7 days: issues moved, code merged, decisions in Slack.
2. Compare that with the plan: the deadline, what's left, and the pace so far.
3. List red flags, each with a link.
4. Say where the project is in its lifecycle, in one sentence.
5. Suggest three questions to ask the team.

## Output
A comment on the audit task.

## Rules
- Check the work, not what people said in meetings.
- A red flag is a reason to ask, not a conclusion.
