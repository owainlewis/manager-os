# Team page update

## When to use
After a 1:1, or when something about a person changes.

## Reads
- The person's page under Team in Notion
- The latest 1:1 transcript in Zoom

## Steps
1. Read the page and the transcript.
2. Propose changes: goals in their words, promises on either side, how they like to work, one dated note if something important happened.
3. Propose removing lines that are no longer true.
4. Show each change as before and after.
5. Save only the changes I approve.

## Output
An updated team page.

## Rules
- Keep the page under one screen.
- Write only what I'd say to their face.
- Don't paste the transcript into the page.
