# How we work

## Meetings
- Monday 10am: Payments leads sync (me, Hannah, Sam, Priya, Daniel, Elena, Aisha). 30 minutes.
- Wednesday 4pm: demo of what shipped. Everyone welcome.
- 1:1s with each direct report every week or every other week. Times are on each Team page.
- Meetings are recorded in Zoom unless someone asks to stop. Transcripts stay in Zoom.

## Work
- Every piece of work is a Linear issue. If it's not in Linear, it isn't planned.
- Weekly cycles start on Monday.
- Agent work gets the "agent" label. The agent reports back as a comment on the issue.

## Code review
- Every pull request needs one approval.
- The code review agent reviews first. A person reviews second.
- Target: first review within one working day.

## Releases
- Release on Tuesday and Thursday, after the regression suite passes.
- QA signs off any change to payouts or money movement.

## On call
- One engineer per week, rota in PagerDuty. Hand over on Monday at the leads sync.
